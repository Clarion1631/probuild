# Send to ProBuild — browser extension

Right-click any product page (Lowe's, Home Depot, a tile vendor, anywhere) and
send the text straight to ProBuild's Design Catalog importer. Clips land in an
inbox on **Settings → Design Catalog**, where one click runs the same AI
extraction used for pasted text and PDFs.

## Install (Chrome / Edge — internal use, no store needed)

1. Open `chrome://extensions` (or `edge://extensions`)
2. Turn on **Developer mode** (top right)
3. Click **Load unpacked** and pick this `extension/` folder
4. Make sure you're signed in to ProBuild in the same browser

## Use

- Select the product details on any page → right-click → **Send selection to ProBuild**
- Or just right-click anywhere → **Send page to ProBuild catalog** (sends the whole page text)
- Review and save under **Settings → Design Catalog → Clips inbox**

Auth uses your existing ProBuild session — if you're signed out, the extension
opens the login page; sign in and send again.

## Publishing to the Chrome Web Store (optional, later)

Needs a one-time $5 developer registration, real icons, and a privacy
disclosure. Not required for the team's day-to-day use via Load unpacked.
